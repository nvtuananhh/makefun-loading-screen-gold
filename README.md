## What it does

`main.py` (Python 3, standard library only, no network) writes
one loading-screen tip to `/output/entry.txt` — a line for
stressed developers and AI coding agents, sharp enough to land
mid-build:

> Tip: while this loads, your AI pair programmer has already rewritten this function twice and is now silently judging your variable names.

The tip is 137 characters long. The program asserts the gate
itself (1–200 characters, single line, not only whitespace)
before writing. It speaks to both audiences at once: the
developer waiting on the build and the AI pair programmer
doing the rewriting. The twist lands in the final words — the
AI is not helping, it is silently judging your variable names. One sentence, one twist at the end, no coffee
joke, no deadline joke, no compile joke. The number is the
joke's spine: the function was rewritten twice while the
developer just waited, and the judgement is what the loading
bar was hiding.

## How to run

```sh
python3 main.py
```

Writes one loading-screen tip (137 characters) to `/output/entry.txt`.
